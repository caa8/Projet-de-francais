# VisionTech — Les lunettes intelligentes

Projet scolaire en français réalisé en HTML, CSS et JavaScript.

## Fichiers
- `index.html` : contenu et structure du site
- `style.css` : design responsive
- `script.js` : menu mobile

## Tester sur son ordinateur
1. Téléchargez et décompressez le dossier.
2. Ouvrez `index.html` dans un navigateur.

## Publier avec GitHub Pages
1. Connectez-vous à https://github.com/ ou créez un compte.
2. Cliquez sur **New repository**.
3. Nommez le dépôt `lunettes-intelligentes` et choisissez **Public**.
4. Cliquez sur **Create repository**.
5. Dans le dépôt, cliquez sur **Add file → Upload files**.
6. Téléversez `index.html`, `style.css` et `script.js` (les trois fichiers doivent être à la racine, pas dans un sous-dossier).
7. Cliquez sur **Commit changes**.
8. Ouvrez **Settings → Pages**.
9. Sous **Build and deployment**, choisissez **Deploy from a branch**.
10. Choisissez la branche `main` et le dossier `/(root)`, puis cliquez sur **Save**.
11. Attendez quelques minutes. La page GitHub Pages affichera l'adresse publique du site, généralement :
   `https://VOTRE-NOM.github.io/lunettes-intelligentes/`

## À personnaliser avant de rendre le projet
Ajoutez votre nom, votre classe et le nom de l'enseignante si nécessaire. Vous pouvez ajouter ces informations dans la section d'introduction ou dans le pied de page.

## Remarque
La police est chargée depuis Google Fonts lorsqu'une connexion Internet est disponible. Le site fonctionne aussi sans elle avec une police de remplacement. Le dessin des lunettes est un SVG intégré au HTML, donc il ne dépend pas d'un fichier image externe.
